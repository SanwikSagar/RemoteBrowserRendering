1. **Go to Render Dashboard:**
   ```
   https://dashboard.render.com
   ```

2. **Sign up/Login:**
   - Use your GitHub account (instant signup)

3. **Create Web Service:**
   - Click "New +" → "Web Service"
   - Select "RemoteBrowserRendering" repository
   - Everything is auto-configured from render.yaml
   - Click "Create Web Service"

4. **Wait 10 Minutes:**
   - Render installs Chromium (~600MB)
   - Installs Node.js dependencies
   - Starts your server

5. **Your Browser Will Be Live:**
   ```
   https://remote-browser-backend.onrender.com
   ```

## 🐛 Troubleshooting Quick Reference

| Issue | Solution |
|-------|----------|
| Build fails on Render | Check logs, try "Clear build cache" |
| Service crashes | Reduce maxBrowsers to 2, lower resolution |
| Can't connect | Wait 30s for cold start, check service is "Live" |
| Slow performance | Normal on free tier, use 30 FPS, 70% quality |
| Memory errors | Reduce browser instances, lower resolution |
